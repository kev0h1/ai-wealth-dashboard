# Retired

This Expo project is retired. A Capacitor wrap of the web app shipped instead;
see `capacitor-spike/` and the project memory for that decision. Nothing syncs
into this tree any more, `mobile/lib/shared/` is a frozen snapshot of
`shared/src` as of the last sync and must not be treated as current, and
`mobile/docs/porting/` is kept as the reference spec for the web-to-mobile port.
