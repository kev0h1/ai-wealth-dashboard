# G449 filed transfers design round

Operate mode. Extend the established Spend and SheetFrame system with a permanent audit view. Fictional fixtures only. No production API calls, filing changes or preferences are authorised by preview interactions.

## Direction contract

THESIS: a quiet, permanent receipt for moved money, retained after review. Compare compact history against evidence first, with the same five selected-period series and twelve all-time series.

OWN-WORLD: Figtree prose, JetBrains Mono money, slate canvas and solid shared sheets, ink figures, indigo actions and hairlines. No new visual identity, gradients, alarm colours or decorative account symbols.

STORY: tap a period's Moved separately amount, the all-time menu row or the review's automatic-filing link. Read amount, route, dates and provenance; undo a series and see its legs return to review without double-counting the money.

FIRST VIEWPORT: a shared full-height SheetFrame with title, period or all-time scope, count and qualification above newest-first series. Three series per page. A puts evidence behind disclosures; B makes the reason immediately readable. Fixed pagination and Done sit below an independently scrolling body.

FORM: local extension with two coded variants required by AGENTS.md, so no concept-seed or new-world round. The Spend amount reconciles to the whole selected scope, not just the visible page. Review opens the Sorted-filed filter so its series count is truthful. Signed legs remain distinct from the unsigned counted movement.

Every series figure is labelled Total. Cadence describes the recurrence, while the figure adds the historical payments in the current view.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

The current API exposes only AI-filed pairs without pagination. Production work after selection must expand the authoritative data scope and reuse the G442 undo/review and H145 recompute paths. This prototype makes no claim that the new endpoint or production component exists. Preserve DESIGN.md during the design round.
