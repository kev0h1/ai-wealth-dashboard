## Direction contract

THESIS: Adviser identity should read as a considered signature, not a repeated AI sticker. Explore three different doses of identity without redesigning the financial cards.

OWN-WORLD: Existing slate/white surfaces and indigo actions. A uses an unboxed ink Penny signature; B frames the existing mark as a restrained coin seal; C removes card-level marks and concentrates Penny in one labelled adviser door. No new logo, sparkle or decorative gradient.

STORY: Compare the same Card detail, Cover plan, Payday plan and Covered examples. Covered remains a financial verdict, never falsely labelled as Penny-authored advice. Read the evidence, recognise the next action, and find Penny without decoding a new navigation model.

FIRST VIEWPORT: A 390px phone column shows Card detail and the start of Cover plan, with the raised nav visible. Desktop keeps that working column beside concise comparison notes. Primary controls are at least 44px. The stack and individual cards are deep-linkable in both themes.

FORM: Local component-family exploration inside the established app, code-led. No replacement-world seed or image comp: the deliverable is three working coded variants, as requested by the board. Frontend Design substitutes for the unavailable design-taste-frontend skill; Impeccable polishes the components. Its context launcher was unavailable, so project context was read directly.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Options

- A Quiet signature: sentence-case ink attribution, no pill fill, solid indigo action with a restrained 12px radius, existing raised gradient adviser door without the purple halo. Gradient only at the adviser entry.
- B Coin seal: the canonical mark in a thin circular indigo seal, sentence-case attribution, slightly deeper indigo actions with a 10px radius, round raised adviser control. Gradient only on that adviser control and the local adviser-header example.
- C One adviser door: quiet card-kind labels without repeated Penny badges, tonal indigo primary actions, and a neutral raised adviser control with a small gradient mark. The gradient identifies the adviser destination, not ordinary facts or actions.

Current production remains a separate comparison, not a fourth new direction. These are different identity systems, not different calculations. All examples are synthetic. Card and navigation actions are intercepted locally; the Penny door opens a labelled local demonstration, never a customer chat or bank action.
